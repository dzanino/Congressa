Program konferencie do telefónov účastníkov. Za jedno popoludnie.

The conference programme in your attendees' phones. In one afternoon.

Dve cesty. Bez servera: účastníci si program načítajú sami z vášho webu alebo PDF — vy len rozdáte QR kód. So serverom: navyše push oznamy, zmeny programu naživo, prihlášky na večeru či výlet s kapacitou. Obe zadarmo, obe pre iPhone aj Android.

Two paths. Without a server: attendees load the programme themselves from your website or PDF — you just hand out a QR code. With a server: plus push announcements, live programme changes, sign-up for dinners or trips with capacity. Both free, both for iPhone and Android.

CESTA A · bez servera · 10 minútPATH A · no server · 10 minutes

Účastníci si program načítajú sami — vy rozdáte QR kód

Attendees load the programme themselves — you hand out a QR code

Vhodné pre každú konferenciu, ktorá má program na webe alebo v PDF. Nič neinštalujete, nič nespravujete.

Right for any conference with a programme on a website or in a PDF. Nothing to install, nothing to run.

  1. Nainštalujte si Congressu (iPhone alebo Android) a v nej Načítať program → Prečítať web alebo PDF: zadajte adresu webu konferencie (alebo otvorte PDF programu). Skontrolujte rozpoznané body — typ, časy, sály — a schváľte. Trvá 2–5 minút.
  2. Install Congressa (iPhone or Android) and use Load programme → Read website or PDF: enter the conference website (or open the programme PDF). Check the recognised items — type, times, rooms — and approve. Takes 2–5 minutes.
  3. Vyrobte QR kód: obrazovka Teraz → Zdieľať program kolegom (QR kód) → Uložiť kód ako obrázok. Kód nesie adresu vášho webu; kto ho naskenuje, dostane rovnaký sprievodca importu. Pod kódom je aj veta pre tých, čo appku ešte nemajú (App Store / Google Play).
  4. Make the QR code: Now screen → Share the programme (QR code) → Save the code as an image. The code carries your website address; whoever scans it gets the same import assistant. Below the code there is a line for those without the app yet (App Store / Google Play).
  5. Rozdajte ho: na registračný pult, na prvý slide, do e-mailu účastníkom, na web konferencie. Účastník naskenuje Fotoaparátom — Congressa sa otvorí sama (alebo v appke Naskenovať QR kód).
  6. Hand it out: registration desk, first slide, attendee e-mail, conference website. The attendee scans it with the Camera — Congressa opens by itself (or Scan QR code inside the app).
Čo účastník dostane: program po dňoch offline, Teraz (čo prebieha, čo nasleduje, kam ísť), Môj plán s pripomienkami pred označenými bodmi aj jednotlivými prednáškami, hľadanie podľa priezviska, potvrdenie o účasti v PDF. Čo nedostane: vaše oznamy naživo a prihlasovanie — na to je cesta B.
What the attendee gets: the programme by day offline, Now (what's on, what's next, where to go), My plan with reminders before starred items and individual talks, search by surname, a PDF certificate of attendance. What they don't get: your live announcements and sign-ups — that's path B.

Tip: ak je program na webe len ako obrázok alebo je web zložitý, pošlite účastníkom PDF programu — Congressa číta textové PDF spoľahlivo (nie skeny).

Tip: if the programme is only an image on the website or the site is complex, send attendees the programme PDF — Congressa reads text PDFs reliably (not scans).

CESTA B · so serverom · asi 1 hodina, razPATH B · with a server · about 1 hour, once

Push oznamy, zmeny naživo, prihlášky s kapacitou

Push announcements, live changes, sign-ups with capacity

Potrebujete jeden Mac (spravuje program) a jeden počítač, ktorý beží počas konferencie (server — môže to byť ten istý Mac). Server je jeden súbor v Pythone, bez inštalácie čohokoľvek ďalšieho.

You need one Mac (to manage the programme) and one computer running during the conference (the server — it can be the same Mac). The server is a single Python file, nothing else to install.

1 · Program v Mac aplikácii (20 min)

1 · The programme in the Mac app (20 min)

  1. Mac aplikácia Congressa (App Store — Mac verzia je v tej istej appke; alebo napíšte, pošlem build). Mac je vždy v režime organizátora.
  2. Congressa for Mac (App Store — the Mac version is the same app; or write to me and I'll send a build). The Mac is always in organiser mode.
  3. Import programu → Načítať z webu alebo Otvoriť PDF. Skontrolujte typy a časy, Nahradiť program. Pri neznámych weboch pomôže Rozpoznať pomocou AI (server s kľúčom Claude, cent za program).
  4. Import programme → Load from website or Open PDF. Check types and times, Replace programme. For unusual websites use Recognise with AI (server with a Claude key, cents per programme).
  5. Doplňte, čo účastníkom pomôže: sály s navigáciou, kontaktné osoby s telefónom (výlet, večera), pri večeri/výlete Vyžaduje prihlásenie + kapacita, Upozorniť všetkých pri bodoch, ktoré nemá nikto zmeškať.
  6. Add what helps attendees: rooms with navigation, contact persons with phone (trip, dinner), Requires sign-up + capacity on dinners/trips, Notify everyone on items nobody should miss.
  7. Účastníci a kódy (voliteľné): CSV so zoznamom → vygenerované kódy → skupiny (výbor, prednášajúci). Kód odomkne vyhradené body a cielené oznamy.
  8. Attendees and codes (optional): CSV list → generated codes → groups (board, speakers). A code unlocks reserved items and targeted announcements.

2 · Server (15 min, jedno rozkliknutie)

2 · The server (15 min, one double-click)

⬇︎ Balík servera pre Mac (zip, 45 kB)Server package for Mac (zip, 45 kB) 📄 PDF: Ako pripraviť konferenciuPDF: How to prepare a conference (SK) 📄 PDF: Správa servera na diaľkuPDF: Managing the server remotely (SK)
  1. Rozbaľte zip a dvojklikom spustite START_CONGRESSA.command (prvýkrát pravý klik → Otvoriť). Skript server nainštaluje do ~/Congressa_server, nastaví automatický štart po zapnutí Macu a nezaspávanie, spustí ho a vypíše adresu servera a admin heslo. Ak Mac vypýta „command line developer tools“ → Inštalovať a spustiť znova.
  2. Unzip and double-click START_CONGRESSA.command (first time: right-click → Open). The script installs the server into ~/Congressa_server, sets it to start automatically and keep the Mac awake, starts it and prints the server address and admin password. If the Mac asks for "command line developer tools" → Install and run again.
  3. Verejná adresa (účastníci nie sú vo vašej Wi-Fi): nainštalujte Tailscale, prihláste sa, na login.tailscale.com → DNS zapnite MagicDNS a HTTPS Certificates, a spustite START znova — vypíše stabilnú https adresu. Zadarmo, dáta ostávajú na vašom Macu.
  4. Public address (attendees are not on your Wi-Fi): install Tailscale, sign in, enable MagicDNS and HTTPS Certificates under DNS on login.tailscale.com, and run START again — it prints a stable https address. Free, data stays on your Mac.
  5. Push pre iPhone (10 min, raz): v Apple Developer účte vytvorte APNs kľúč (.p8), uložte ho do ~/Congressa_server/apns/, do .env doplňte Team ID a CONGRESSA_APNS_ENV=production, START znova. Postup krok za krokom je v PDF vyššie. Bez tohto kroku všetko funguje, len iPhony nedostanú push (Android ho nemá zatiaľ vôbec — oznamy si stiahne pri otvorení appky).
  6. Push for iPhone (10 min, once): create an APNs key (.p8) in your Apple Developer account, put it into ~/Congressa_server/apns/, add the Team ID and CONGRESSA_APNS_ENV=production to .env, run START again. Step by step in the PDF above. Without this step everything works, only iPhones get no push (Android has none yet — it fetches announcements when the app is opened).

3 · Publikovať a rozdať QR kód (5 min)

3 · Publish and hand out the QR code (5 min)

  1. Mac appka → Server a push → adresa servera + admin heslo → Overiť pripojenie → Publikovať program na server (a Odoslať zoznam účastníkov, ak ho máte).
  2. Mac app → Server and push → server address + admin password → Test connection → Publish programme to server (and Send attendee list, if you have one).
  3. Tam istom mieste QR kód pre účastníkov → uložiť ako obrázok → plagát pri registrácii, úvodný slide, e-mail. Kód nesie adresu servera; účastník ho naskenuje raz a odvtedy dostáva program, oznamy aj prihlášky. Rovnaký kód pre iPhone aj Android.
  4. Same place: QR code for attendees → save as image → poster at registration, opening slide, e-mail. The code carries the server address; the attendee scans it once and from then on receives the programme, announcements and sign-ups. The same code for iPhone and Android.

During the conference

📣

Okamžitý oznam

Instant announcement

Mac → Server a push → Poslať oznam („Obed je v átriu“). Uloží sa do programu a iPhony dostanú push. Dá sa aj z prehliadača: adresa-servera/admin.

Mac → Server and push → Send announcement ("Lunch is in the atrium"). Saved into the programme, iPhones get a push. Also from a browser: server-address/admin.

🔁

Zmena programu

Programme change

Upravte bod (čas, sála, zrušenie) → Publikovať a upozorniť všetkých. Appky si zmenu stiahnu a účastníkom, ktorých sa týka, ju ukážu v Oznamoch.

Edit the item (time, room, cancelled) → Publish and notify everyone. Apps fetch the change and show it in Notices to the attendees concerned.

📋

Kto je prihlásený

Who signed up

Server a push → Prihlásení na body programu — počty, čakacia listina, CSV prezenčná listina pre reštauráciu či autobus.

Server and push → Registrations — counts, waiting list, CSV attendance list for the restaurant or the bus.

⏰

Pripomienky idú samy

Reminders run by themselves

Server pošle push pred každým bodom podľa nastavenia účastníka (predvolene 15 min); Android si pripomienky plánuje v telefóne. Vy nerobíte nič.

The server sends a push before each item per the attendee's setting (15 min by default); Android schedules reminders on the phone. You do nothing.

FAQ

Koľko to stojí?What does it cost?

Nič. Aplikácia aj server sú zadarmo, bez limitu účastníkov. Kto chce, môže autora podporiť dobrovoľným príspevkom v appke.

Nothing. The app and the server are free, with no attendee limit. Anyone who wants can support the author with an optional tip in the app.

Kde sú dáta účastníkov?Where is attendee data?

Na vašom serveri (Macu). Congressa nemá žiadny cloud autora; účastníkom sa vydáva len program. Mená a e-maily neopúšťajú váš počítač.

On your server (Mac). Congressa has no author-run cloud; attendees only receive the programme. Names and e-mails never leave your computer.

Musí to byť Mac?Does it have to be a Mac?

Server beží všade, kde je Python 3 (Mac, Linux, Windows, lacný VPS). Administrácia programu je zatiaľ len v Mac aplikácii; na iPade funguje tiež (Nastavenia → režim organizátora). Bez Macu použite cestu A.

The server runs anywhere with Python 3 (Mac, Linux, Windows, a cheap VPS). Programme administration is currently in the Mac app only; it also works on iPad (Settings → organiser mode). Without a Mac, use path A.

Čo ak vypadne internet v sále?What if the venue loses internet?

Nič sa nestane: program aj pripomienky sú v telefónoch. Push oznamy a nové zmeny prídu, keď sa sieť vráti.

Nothing happens: the programme and reminders are on the phones. Push announcements and new changes arrive once the network is back.

Android vs. iPhone — je rozdiel?Android vs. iPhone — any difference?

Rovnaký program, QR kód, prihlášky aj pripomienky. Android zatiaľ nedostáva push zo servera — oznamy si stiahne pri otvorení appky (a každé 3 minúty, kým je na obrazovke).

Same programme, QR code, sign-ups and reminders. Android does not yet receive push from the server — it fetches announcements when the app is opened (and every 3 minutes while on screen).

Program je v dvoch jazykoch / má paralelné sekcieThe programme is bilingual / has parallel sessions

Paralelné sekcie sú bežné — každá má svoju sálu a účastník si vyberá hviezdičkou; kolízie appka ukáže. Jazyk programu je taký, aký publikujete; rozhranie appky je slovenské aj anglické.

Parallel sessions are normal — each has its room and the attendee picks with a star; clashes are shown. The programme language is whatever you publish; the app interface is Slovak and English.
