# Congressa – web

Statická stránka pre GitHub Pages: `index.html` (SK/EN), `organizator.html` (návod pre organizátora),
`open.html` (inteligentný odkaz z QR kódu – iPhone → App Store, Android → Google Play, potom sa načíta program),
`privacy.html`, `support.html` a `assets/` (ikony, odznaky obchodov, PDF návody).

Zdroj je priečinok `web/` v hlavnom repozitári projektu. Balík servera sa tu **nezverejňuje** – organizátorom
ho autor posiela na požiadanie (congressa_main@icloud.com).
